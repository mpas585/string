      サーバ側の実ファイルには Google OAuth の client_id / secret や
      mail_from が入っており、GitHub 版は空のままです。上書きすると
      Google ログインが止まるので、今回は同梱していません。
      採点ゲームを復活させたくなったときだけ、config/app.php の配列に
          'game_enabled' => true,
      の1行を足してください（既定は false ＝ 出さない）。

  src/account.js, src/audio/scheduler.js
      本番サーバのものが GitHub 版より新しかったため、今回は触っていません。

■ tools/langjson.py の使い方（追加分）
  python tools/langjson.py includes/lang/ja.php            JSON を出力
  python tools/langjson.py includes/lang/ja.php --check     読めるかだけ確かめる
  python tools/langjson.py includes/lang/*.php --parity     4言語のキーがそろっているか
  読めないときは「何行目の何が読めないか」を出して止まります。
